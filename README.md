# Tatikis Xanut 3D

**Симулятор ереванского магазинчика от первого лица**

Вы — хозяйка лавки. Розовый туф, лаваш, гата, тархун, гора Арарат за окном и живые покупатели на армянском.

## Запуск

```bash
cd tatikis-xanut
npm install
npm run dev
```

Открой http://localhost:3000

## Управление

| Действие | Клавиша / жест |
|----------|----------------|
| Ходить | WASD / стрелки / джойстик |
| Смотреть | Мышь / свайп |
| Обслужить клиента | E или кнопка |
| Реплики хозяйки | Кнопки внизу |
| Закупить товар | Кнопка (-2000 ֏) |

## Деплой на Cloudflare Pages

- Build command: `npm run build`
- Output directory: `dist`
